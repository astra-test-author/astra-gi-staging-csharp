# astra-gi-staging-csharp

**Staging test GI — not for players.**

This is a minimal C# BepInEx game integration for Lethal Company (Unity Mono),
built only to rehearse the Astra games catalogue's staging "done when" (a
non-owner account publishes a GI and it gets signed) end to end, as a real
third-party author would have to. It logs one line at startup and does
nothing else. Do not install it.

Published from the `astra-test-author` GitHub organisation, a test
organisation the owner created for exactly this kind of walk — it is not
`mihailinl`, so ingest treats it as a non-first-party (community) release.
